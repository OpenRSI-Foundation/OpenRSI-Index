# ✨ News

Milestones from OpenRSI Index and RSI Harness, newest first. Code updates use the date they merged in Los Angeles time; announcements use their published dates.

[← Back to OpenRSI Index](README.md#-news)

## November 2026

- **[2026-11-13] Lower-overhead cluster evaluation.** RSI Harness now pauses Work and binds its workspace read-only into a fresh cluster Judge, avoiding per-round workspace copies. The update also strengthens Work sandboxing and checks the workspace before evaluation. [Workspace mounts](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/347) · [Work sandboxing](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/346)
- **[2026-11-12] Task-defined evaluation budgets.** Tasks can specify their submission budget. A budget of one selects a single final evaluation, including evaluation at the deadline when the agent has not submitted. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/342)
- **[2026-11-12] Tighter agent configuration.** Harness-managed agent launches restrict model switching and disable account-level tools; supported subagents inherit the run's model, while unsupported subagent paths are disabled. [Scope and limitations](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/343)
- **[2026-11-09] OpenRSI × SGLang-Omni.** We published a report documenting **14 upstream-merged PRs across eight speech and omni model families**, with H100/H200 measurements, evaluation protocols and attribution notes. The work combines agent-driven optimization with human task design and upstream review. [Read the report](https://index.openrsi.foundation/blog/2026/openrsi-sglang-omni/)
- **[2026-11-06] SingularityCE and allocation launches.** RSI Harness adds SingularityCE support for compatible cluster configurations, runs within existing PBS/PJM allocations, and improves provider backoff and cancellation handling. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/334)
- **[2026-11-05] SGLang-Omni task collection released.** The public SGNOMI collection includes **12 task packages covering 10 model configurations across eight model families**, with final streaming and non-streaming tasks and links to related upstream PRs. These are published task packages; the release did not rerun GPU evaluations. [Browse the collection](rsi-tasks/SGNOMI/) · [Publication](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/331)
- **[2026-11-04] PBS Pro and Fujitsu PJM adapters.** New single-node scheduler adapters include example profiles for Flow 2.0 and Genkai. The PR records OpenPBS validation and the remaining PJM/site validation scope. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/328)
- **[2026-11-03] Kubernetes adapter.** Build and run jobs can use Kubernetes Jobs with one Pod per allocation, reusing the Apptainer execution engine, Oracle validation and resume support. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/323)

## October 2026

- **[2026-10-31] Local Docker without sudo.** Users with access to a Docker Engine 26+ daemon can run, recover and resume ordinary Linux Docker tasks without a root controller. Managed sandbox tasks still require root. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/310)
- **[2026-10-29] More validation and sandbox options.** RSI Harness adds Slurm Oracle baseline validation, restricted-cluster capability checks, an experimental macOS CPU-only controller, and Modal/Daytona managed sandbox backends. These sandbox backends provide child environments within a run. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/302)
- **[2026-10-21] Resumable research runs.** `rsi-harness resume` continues interrupted runs while retaining workspaces, agent sessions, evaluation history and the best result. Files survive; background processes and GPU memory do not. Codex provider-capacity retries also keep the same session. [Resume](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/286) · [Provider retries](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/289)
- **[2026-10-16] Stronger Judge isolation and Oracle validation.** Hidden Judges default to clean images, with isolated candidate execution and optional independent Judge models. The new Oracle agent runs a task's reference solution through the evaluation path. [Judge isolation](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/263) · [Oracle validation](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/264)
- **[2026-10-12] Seven coding agents.** Qwen Code, Kimi Code, OpenCode, ZCode and pi join Codex and Claude Code on local Docker. The same update introduces public Judges, model access for Judges and a science-task example. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/231)
- **[2026-10-12] Research logs on Hugging Face.** Research trajectories move to the [OpenRSI Index Logs dataset](https://huggingface.co/datasets/OpenRSI-Foundation/OpenRSI-Index-Logs), with publication checks and dataset audits. Explore them in the [RSI Logs Viewer](https://index.openrsi.foundation/logs/). [Publication tooling](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/247)
- **[2026-10-12] First SGLang-Omni research archive.** We published the TTS runtime task and its research logs behind the first upstream optimizations. The historical task and evidence remain linked from the [publication PR](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/237); current per-model tasks are in [SGNOMI](rsi-tasks/SGNOMI/).
- **[2026-10-11] Featured in Jiqizhixin.** Jiqizhixin covered OpenRSI Index and its approach to evaluating research agents on real model-development tasks. [Read the article](https://www.jiqizhixin.com/articles/2026-10-11-3)
- **[2026-10-09] Managed sandboxes.** Work and Judge can use broker-managed Docker or E2B child environments, with resource policies and lifecycle cleanup. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/201)
- **[2026-10-07] First three upstream optimizations.** Three agent-assisted changes landed in SGLang-Omni after maintainer review, improving CosyVoice3 and MOSS-TTS serving. [#2524](https://github.com/sgl-project/sglang-omni/pull/2524) · [#2525](https://github.com/sgl-project/sglang-omni/pull/2525) · [#2555](https://github.com/sgl-project/sglang-omni/pull/2555)
- **[2026-10-07] CPU-only Slurm tasks.** RSI Harness adds single-node CPU Work support through Slurm and Apptainer, including tasks whose Work and Judge both need no GPU. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/193)
- **[2026-10-01] LSF training compatibility.** Job-exclusive LSF allocations now allow multiple CUDA processes. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/155)

## September 2026

- **[2026-09-28] Clearer run completion.** Runs that exhaust their agent time budget now distinguish completed evaluations from runs with no valid submission, rather than recording every timeout as a failure. [Details](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/140)
- **[2026-09-26] Long-run reliability.** Updates improve cluster permissions and GPU release checks, preserve trajectory content during credential redaction, and remove Claude's Stop hook continuation cap. [Cluster fixes](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/135) · [Trajectory and continuation fixes](https://github.com/OpenRSI-Foundation/OpenRSI-Index/pull/136)

[Launch thread](https://x.com/OpenRSI/status/2102831770458890626) · [Contribute a task](https://index.openrsi.foundation/contribute)
